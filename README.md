# Campus Reunite And Recover

create a webiste using full stack on Smart Campus Lost-and-Found with Image Matching

Core Idea: A localized portal where students post lost or found items with photos, locations, and timestamps

Standout Feature: Auto-suggest potential matches between new "found" posts and unresolved "lost" reports using text/tag similarity.
